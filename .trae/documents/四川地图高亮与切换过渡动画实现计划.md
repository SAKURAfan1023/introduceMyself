# 四川地图高亮与切换过渡动画实现计划

## 1. 任务一：四川边界高亮与Hover填充 (Modify `chinese.svg`)

**回答你的问题：** 是的，我可以做到填充四川的色块。SVG 提供了 `fill` 属性，我们可以通过在 SVG 文件内部添加 CSS 样式来实现。当鼠标悬停 (`:hover`) 时，改变 `fill` 属性即可实现色块填充。

**实施步骤：**

1. **编辑文件**：`app/containers/components/mapSvg/img/chinese.svg`
2. **修改样式**：在 `<style>` 标签内添加针对 `#Sichuan` ID 的样式规则。

   * **默认状态**：设置 `stroke` (边界颜色) 和 `stroke-width` (边界粗细) 来高亮边界。

   * **Hover状态**：设置 `#Sichuan:hover`，添加 `fill` (填充颜色) 属性，并增加 `stroke-width` 以增强交互感。该填充属性添加过渡，并且我希望能够做到在鼠标进入的位置记录坐标，以此为坐标画半径能够囊括四川的圆进行扩散，达到完美的丝滑过渡

```css
/* 计划添加的 CSS 示例 */
#Sichuan {
    stroke: #FF4500; /* 亮橙色边界 */
    stroke-width: 2;
    transition: all 0.3s ease; /* 平滑过渡 */
}
#Sichuan:hover {
    fill: #FF4500; /* 悬停时填充颜色 */
    fill-opacity: 0.8;
    stroke-width: 3;
    cursor: pointer;
}
```

## 2. 任务二：地图透明度切换过渡 (Modify `index.tsx`)

**目标**：利用 `scrollYProgress` 实现两个地图图层的平滑切换（Cross-fade）。

**实施步骤：**

1. **编辑文件**：`app/containers/components/mapSvg/index.tsx`
2. **定义透明度变量**：

   * 创建 `opacityChina`：在前半段保持可见 (1)，中间过渡段变为不可见 (0)。

   * 创建 `opacitySichuan`：在前半段保持隐藏 (0)，中间过渡段变为可见 (1)。

   * **过渡区间设计**：为了保证流畅过渡，我们将设定一个交叉区间（例如滚动进度的 0.4 到 0.6）。
3. **应用样式**：

   * 将 `<img alt="China Map">` 替换为 `<motion.img>` 并绑定 `style={{ opacity: opacityChina }}`。

   * 将包裹四川地图的 `div` 替换为 `<motion.div>` (或在现有 div 上添加 motion) 并绑定 `style={{ opacity: opacitySichuan }}`。

**代码逻辑预演：**

```typescript
// 0 -> 0.4: 中国地图显示，四川隐藏
// 0.4 -> 0.6: 交叉过渡 (中国渐隐，四川渐显)
// 0.6 -> 1: 中国隐藏，四川显示
const opacityChina = useTransform(scrollYProgress, [0, 0.4, 0.6], [1, 1, 0]);
const opacitySichuan = useTransform(scrollYProgress, [0, 0.4, 0.6], [0, 0, 1]);
```
