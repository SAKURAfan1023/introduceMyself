# 添加滚动触发的离场/入场动画

## 目标

为 `MouseParallaxHero` 添加基于滚动的离场动画。当页面向下滚动超过 100px 时，图片以与入场相反的方向滑出屏幕（离场）；当滚动回到 100px 以内时，图片再次触发入场动画滑入。

## 实现方案

1.  **引入 `useScroll` 和 `useMotionValueEvent`**
    *   使用 `motion/react` 的 `useScroll` 钩子获取滚动位置。
    *   使用 `useMotionValueEvent` 或 `useEffect` 监听 `scrollY` 的变化。

2.  **状态管理**
    *   创建一个状态 `isVisible` (boolean)，默认为 `true`。
    *   当 `scrollY > 100` 时，设置 `isVisible = false`（触发离场）。
    *   当 `scrollY <= 100` 时，设置 `isVisible = true`（触发入场）。

3.  **更新动画 Variants**
    *   `imageVariants` 已经有了 `hidden`（屏幕外）和 `visible`（屏幕内）。
    *   离场动画 (`exit`) 其实就是回到 `hidden` 状态。
    *   我们将复用 `hidden` 作为离场状态，或者定义一个新的 `exit` 变体如果需要不同的离场参数（但用户要求是“以入场动画相反的animate滑出”，这正好对应 `hidden` 状态的位置）。
    *   为了确保离场动画平滑，我们需要给 `hidden` 状态也添加 `transition` 属性（目前只有 `visible` 有 `transition`）。

4.  **组件结构更新**
    *   在 `ParallaxImage` 中，将 `animate` 属性绑定到 `isVisible` 状态：`animate={isVisible ? "visible" : "hidden"}`。
    *   不再需要 `AnimatePresence`，因为组件并没有从 DOM 中卸载，只是移动到了屏幕外。

5.  **具体步骤**
    *   修改 `MouseParallaxHero`：
        *   添加 `useScroll` 监听。
        *   添加 `useState` 存储 `isVisible`。
        *   将 `isVisible` 传递给 `ParallaxImage`。
    *   修改 `ParallaxImage`：
        *   接收 `isVisible` prop。
        *   更新 `motion.div` 的 `animate` 属性。
    *   修改 `imageVariants`：
        *   为 `hidden` 状态添加 `transition`，确保离场时也有动画效果（可以使用与入场相同的 ease-out 或稍微快一点的 ease-in）。

## 预期效果

*   **初始加载**：`isVisible = true`，图片从屏幕边缘滑入。
*   **向下滚动 > 100px**：`isVisible = false`，图片滑出屏幕（回到初始的屏幕外位置）。
*   **向上滚动 < 100px**：`isVisible = true`，图片再次滑入屏幕。
